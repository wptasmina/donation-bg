## 📌 Project Overview
Flat Donation BG is a modern, responsive, and user-friendly donation platform built using **HTML, CSS, Tailwind CSS, and JavaScript**. It offers a seamless donation experience with an intuitive design, smooth animations, and a fully responsive layout.

## 🎯 Key Features
✅ **Responsive Design** – Optimized for all devices (desktop, tablet, mobile).  
✅ **Modern UI/UX** – Clean, minimal, and engaging interface.  
✅ **Interactive Elements** – Smooth scrolling and animations using JavaScript.  
✅ **Easy Navigation** – Well-structured sections for a seamless experience.  
✅ **Fast & Lightweight** – Built with Tailwind CSS for optimized performance.  

## 🛠️ Technologies Used
- **HTML5** – Structuring the content.  
- **CSS3** – Styling and layout enhancements.  
- **Tailwind CSS** – Utility-first CSS framework for faster development.  
- **JavaScript** – Adding interactivity and animations.
